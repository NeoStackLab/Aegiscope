# Contributing

This repository accepts focused improvements to public product materials and feedback. The application source repository is private at this time.

Choose the closest issue template. For false positives, include the rule name, what you expected and a sanitized explanation. Never attach credential values, browser data, repository contents or unredacted personal paths.

Keep capability statements precise: distinguish implemented from planned, and observed facts from inference and unknowns. Do not describe encrypted traffic as a proven file upload without direct evidence.

Do not submit application source, private configuration, internal implementation details or secrets here. Maintainers may close material belonging in the private engineering repository.
