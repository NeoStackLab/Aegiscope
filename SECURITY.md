# Security Policy

Aegiscope is in Phase 0 and has no production binary.

## Report a vulnerability

Do not publish an exploitable vulnerability, credential, private endpoint, personal path or sensitive sample in a public issue. Use GitHub private vulnerability reporting for this repository when enabled, or contact the maintainers through the account's verified security contact.

Include the affected release/commit, Windows version, concise reproduction, impact and safe proof-of-concept details. Do not include real secrets or private user data.

## Response and release security

Reports will be acknowledged as capacity allows; no response-time guarantee is made during pre-release. Future releases must verify repository, installer version, SHA-256, code-signing status and public archive contents. A checksum detects changes relative to a digest; it does not prove publisher identity.
